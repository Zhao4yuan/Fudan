# 金融科技（国际金融学院）

也和管院一样是商科专业。金融科技主要是把科技手段用到金融里，就业方向包括量化（用计算机做交易）、传统金融等。课程设置上，金融类课程占比更大，科技类相对辅助。

本专业分两个方向：量化科技和金融实务。

一些亮点：

- 全英文授课：专业课全英文，学完知识后不用再“中译英”一遍，可以直接用英文思维去理解金融概念。国际生占比也很高，甚至2025级超过了一半。
- 课程内容：包括金融核心课（微观经济学、投资学、公司金融等），也有Python、区块链、AI在金融中的应用等科技课。科技类课程的深度不如计算机/大数据专业，但比纯金融专业多了一些数据分析训练。
- 职业发展中心：提供一对一职业咨询、简历指导、模拟面试、企业导师对接；暑期实习是必修环节，由中心统一安排对接。因为学院每一届人数很少（金融科技本科2023年才首次招生），所以职业发展中心平均到每个同学身上的精力会比较多。
- 海外交流：学院与哥伦比亚大学、威斯敏斯特大学、新加坡管理大学等有双学位或交换协议。
- 就业去向：传统金融（投行、券商、银行）、量化（量化私募、公募量化、衍生品）、金融科技企业、政府金融监管部门或国际组织。不过这些是研究生的就业去向，本学院本科还没有产生毕业生（你们是第四届）。
- 由于位列物化组，被诸如微电子、大数据等理工科专业竞争导致分数线不是特别高（往年位列不限组的时候分数线是很高的）；并且现在中国的经济处于周期低谷，金融相对不是很热门，报考此专业相当于低位买入（个人观点仅供参考（））

几个常见问题：

- 量化对传统金融知识有要求吗？

有一定要求，模型策略需要结合金融业务逻辑，纯粹懂代码可能不够。

- 量化对数学天赋要求高吗？

不同方向要求不同，有的偏统计分析，有的偏AI建模。现在编程语法可以借助AI辅助，但数理逻辑和判断能力可能也仍然有一定用处。

- 这些技能能不能自己学？

可以，本科阶段内容本身不深，很多知识和工具都可以通过自学或实习补充。选专业不是就业的唯一因素，后续实习和项目经历，以及自学的知识和面试等等也有一定影响。

最后，建议根据自己兴趣和分数情况决定。
